# MAX MiniApp Launcher

Мини-приложение для платформы MAX.

## Возможности

- получение данных пользователя;
- открытие внешнего веб-приложения;
- подготовка к интеграции с OAuth2.

## Структура

- index.html
- css/
- js/
- assets/

## Запуск

Откройте `index.html` локально или разместите проект на HTTPS-сервере.
